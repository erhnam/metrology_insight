# Medición de Corriente RMS — Método Implementado

## Referencia normativa

- **IEC 61000-4-30:2021**, Sección 5.13.1 (Magnitud de corriente) y 5.13.2 (Agregación).
- Clase S: el fabricante especifica el método de medición.

## Método de medición

### RMS por ciclo

La corriente RMS se calcula sobre una ventana de **1 ciclo** de la frecuencia fundamental detectada (20 ms @ 50 Hz, ~16.67 ms @ 60 Hz):

```
I_rms = sqrt( (1/N) * Σ x[n]² )
```

Donde `x[n]` son las muestras ADC del canal de corriente, y `N` es el número de muestras en el ciclo. La implementación usa `calculate_rms()` en `metrology_insight/src/voltage_current.rs`.

### RMS de 10 ciclos

Adicionalmente se calcula internamente un RMS de 10 ciclos contiguos no solapados mediante suma de cuadrados (RMS-of-RMS, §4.5.1), aunque este valor no se persiste en el registro de agregación. Se usa internamente para consistencia con el método de tensión.

### Semi-ciclo

Se calcula Urms(½) para cada semiciclo mediante `UrmsHalfCycle` en `urms.rs`, usado como valor instantáneo (no agregado).

## Agregación

Corriente y tensión se agregan en **los mismos intervalos** dentro de `PqAggregator::push_cycle()`:

| Intervalo | Instancia |
|-----------|-----------|
| 3 s | `agg_3s` |
| 10 min | `agg_10m` |
| 2 h | `agg_2h` |

El método de agregación es RMS-of-RMS conforme a §4.5.1:

```
I_rms_agregado = sqrt( (1/N) * Σ I_rms_ciclo² )
```

Implementado en `aggregator.rs`:
- Acumulación: `self.i_rms_sq[i] += (ph.current.rms)²`
- Finalización: `rec.i_rms[i] = sqrt(self.i_rms_sq[i] * inv_n)`

## Marcado durante eventos

Cuando se detecta un evento de tensión (hueco, sobretensión, interrupción o RVC), el flag `Q_FLAG_EVENT_MARKED` se aplica tanto a la señal de tensión como a la de corriente (`processing.rs`). Los flags `Q_FLAG_PLL_UNSETTLED` y `Q_FLAG_SYNC_INCONSISTENT` se aplican individualmente a cada señal.
