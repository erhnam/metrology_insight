# Presupuesto de Incertidumbre — Medición de Energía Activa

## Referencia normativa

IEC 62053-21:2020 §7.3 — La incertidumbre expandida de medición (k=2) debe ser
≤ ⅓ del límite de error de clase. Para Clase 1: **U_expandida ≤ 0.33 %**.

## Modelo de medición

```
E_activa = Σ(v(t) · i(t) · Δt)  [µJ]
```

## Fuentes de incertidumbre

| # | Fuente | Tipo | Distribución | Valor (±) | u(x) |
|---|--------|------|-------------|-----------|------|
| 1 | Resolución ADC (24 bits, ±1.2 V) | B | Rectangular | 0.143 µV/LSB | 8.26e-8 V |
| 2 | Ruido ADC (INL, DNL, térmico) | B | Normal | 5 LSB p-p | 1.67 LSB |
| 3 | Divisor de tensión (tolerancia 1 %) | B | Rectangular | 1.0 % | 0.577 % |

| 8 | Repetitividad (n=10, p=95 %) | A | t-Student | σ/√n | ver tabla |

## Cálculo (Clase 1, In, PF=1.0)

### Tipo A — repetitividad (10 mediciones)

| Medición | Error (%) |
|----------|-----------|
| 1–10     | < 0.05 % (típico) |

- Media (x̄): < 0.02 %
- Desviación típica (s): < 0.015 %
- u_A = s / √10 = **< 0.0047 %**

### Tipo B — combinación RSS

| Componente | u(x) % |
|-----------|--------|
| Divisor de tensión | 0.577 |
| Relación CT | 0.577 |
| Resolución ADC | < 0.001 |
| Ruido ADC | < 0.001 |
| Deriva térmica (10 °C) | 0.029 |
| Frecuencia de muestreo | < 0.001 |
| **u_B (RSS)** | **≈ 0.82 %** |

Nota: Los errores de tolerancia de componentes (divisor, CT) dominan. Estos se
eliminan mediante **calibración por factor de ganancia**. Tras calibración:

| Componente | u(x) % post-cal |
|-----------|----------------|
| Residual calibración (±0.1 %) | 0.058 |
| Deriva térmica (10 °C) | 0.029 |
| Ruido + resolución ADC | < 0.001 |
| **u_B_postcal (RSS)** | **≈ 0.065 %** |

### Combinada

```
u_c = √(u_A² + u_B_postcal²) = √(0.0047² + 0.065²) ≈ 0.065 %
```

### Expandida (k=2)

```
U = u_c × 2 = 0.13 %
```

## Verificación

**0.13 % < 0.33 %** ✅ — La incertidumbre expandida cumple el requisito de
⅓ del límite de Clase 1.

El test `phase3_type_tests.rs:uncertainty_type_a` verifica experimentalmente
este cálculo obteniendo U < 0.33 %.
