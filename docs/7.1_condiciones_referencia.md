# Condiciones de Referencia — IEC 62053-21:2020 (§7.1)

Según IEC 62053-21:2020 §7.1, las siguientes condiciones de referencia se aplican
durante las pruebas de exactitud de las Tablas 3 y 4.

## Tabla de condiciones

| Parámetro | Condición de referencia | Notas |
|-----------|------------------------|-------|
| Temperatura ambiente | 23 °C ± 2 °C | Medida junto al contador |
| Tensión de alimentación | Un ± 1 % | Un = valor nominal configurado |
| Frecuencia | fn ± 0.3 % | fn = 50 Hz o 60 Hz según `GridFrequency` |
| Forma de onda | Senoidal | Distorsión armónica total < 1 % |
| Factor de potencia | cos φ = 1.0 | Salvo que la prueba especifique otro (0.5L, 0.8C) |
| Carga | Balanceada | Salvo prueba de carga desequilibrada |
| Campo magnético externo | Apantallado | < 0.05 mT |

## Generación de señales de referencia

Las señales sintéticas se generan con `generate_signal.rs` o `generate.py`
usando los valores nominales de `StandardElectricalValues`:

- Tensión: `v(t) = √2 × Un × sin(2π × fn × t)`
- Corriente: `i(t) = √2 × Irms × sin(2π × fn × t − φ)` donde φ = arccos(PF)
- Energía de referencia: `E_ref = Un × Irms × PF × Δt` (integración analítica)

## Verificación del error

```
error(%) = (E_medida − E_referencia) / E_referencia × 100
```

Donde `E_medida` es la energía activa acumulada por `energy.rs` y `E_referencia`
se calcula analíticamente. Para Clase 1:

- Límite Tabla 3: |error| ≤ 1.0 % (hasta ±1.5 % en bornes del rango)
- Límite Tabla 4: |error_adicional| ≤ 0.2–1.0 % según magnitud de influencia
