# Desequilibrio de Corriente — Método Implementado

## Referencia normativa

- **IEC 61000-4-30:2021**, Sección 5.13.6 (Desequilibrio de corriente).
- Clase S: el fabricante especifica el método.

## Método: Componentes Simétricas de Fortescue

Se aplica la transformada de Fortescue a las tres corrientes de fase para obtener las componentes simétricas:

```
I0 = (Ia + Ib + Ic) / 3
I1 = (Ia + a·Ib + a²·Ic) / 3
I2 = (Ia + a²·Ib + a·Ic) / 3
```

Donde `a = e^(j·120°) = -1/2 + j·√3/2`.

### Entradas

- `i_rms[3]`: Magnitudes RMS de corriente por fase.
- `i_angles[3]`: Ángulos de fase (desde `update_phase_angles`).

### Salidas

| Símbolo | Magnitud | Descripción |
|---|---|---|
| `I1` | `i1_pos_seq` | Secuencia positiva (directa) |
| `I2` | `i2_neg_seq` | Secuencia negativa (inversa) |
| `I0` | `i0_zero_seq` | Secuencia cero (homopolar) |
| `u2(%)` | `u2_i_ratio_pct` | `I2/I1 × 100%` |
| `u0(%)` | `u0_i_ratio_pct` | `I0/I1 × 100%` |

## Implementación

Archivo: `metrology_insight/src/unbalance.rs`, función `calculate_current_unbalance()`.

Reutiliza la misma función de componentes simétricas que el desequilibrio de tensión (`symmetrical_components()`), cambiando solo las magnitudes y ángulos de entrada.
